# CAGE — Global Agent Standards (All Modes)

> These rules are NON-NEGOTIABLE and apply in every Roo mode.

**Authority:** [`AGENTS.md`](../../AGENTS.md) at the repository root is the
single source of truth for all contributor and AI-agent standards (commit
conventions, branch naming, code standards, deployment rules, debugging
standards, compliance obligations, and architecture standards). Read it in
full before acting in this repository.

This file and the other `.roo/rules-<mode>/` files exist only to route
Roo-specific mode context back to `AGENTS.md` — they do not duplicate its
content. If you find a conflict between this directory and `AGENTS.md`,
`AGENTS.md` wins.
