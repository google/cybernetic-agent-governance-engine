# Example CAGE NormativeProvider Plugin (`contrib/example-normative-provider`)

Minimal inbound reference skeleton demonstrating how an external partner package implements the CAGE `NormativeProvider` seam and registers it via Python `entry_points` (`group = "cage.normative_providers"`) without modifying any file in `src/gateway/`.

See [`docs/PARTNER_SPI.md`](../../docs/PARTNER_SPI.md) for the complete Partner Integration SPI specification.
